# Портал звернень клієнтів (Request Portal)

Курсова робота з дисципліни «Веб-технології та веб-дизайн».
Тема: **«Вебсистема керування зверненнями клієнтів корпоративного сайту»**.

## 📖 Про проєкт
Система дозволяє клієнтам залишати звернення щодо наданих послуг, а менеджерам — централізовано обробляти ці звернення, змінювати їхній статус та вести історію комунікації.

**Основні ролі:**
*   **Клієнт** — перегляд каталогу послуг, створення звернення, перегляд історії та статусів своїх звернень.
*   **Менеджер** — перегляд усіх звернень, призначення себе відповідальним, зміна статусів (Нова → В роботі → Завершена / Відхилена), додавання внутрішніх та публічних коментарів.

## 🛠️ Технологічний стек
*   **Backend:** PHP 8.2+
*   **Framework:** Laravel 11
*   **Frontend:** Blade, Bootstrap 5, Vite
*   **Database:** MySQL 8.0
*   **Testing:** PHPUnit (Unit та Feature тести)
