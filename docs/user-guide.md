# Керівництво користувача

## 1. Вхід та реєстрація в системі

### Реєстрація

1. Відкрийте сторінку **Реєстрація**.
2. Заповніть ім’я, адресу електронної пошти та пароль.
3. Підтвердьте пароль і натисніть **Зареєструватися**.
4. Після успішної реєстрації система автоматично створить обліковий запис із роллю **Клієнт**.

### Вхід

1. Відкрийте сторінку **Вхід**.
2. Введіть електронну пошту та пароль.
3. Натисніть **Увійти**.

Після входу клієнт отримує доступ до власних звернень і можливості створювати нові звернення. Не передавайте пароль іншим особам.

## 2. Перегляд каталогу послуг та пошук

Каталог послуг доступний усім відвідувачам на головній сторінці та за адресою `/services`.

Для кожної послуги відображаються:

- **Назва послуги**;
- **опис**;
- доступність послуги для створення нового звернення.

Щоб знайти потрібну послугу, скористайтеся пошуком у каталозі, якщо він доступний у поточному інтерфейсі, або перегляньте список послуг за назвою.

## 3. Створення нового звернення

Для створення звернення увійдіть у систему та відкрийте розділ **Мої звернення → Нове звернення**.

Заповніть форму:

| Поле | Опис | Обов’язковість |
|---|---|---|
| **Послуга** | Послуга, щодо якої створюється звернення | Обов’язкове |
| **Тема** | Короткий заголовок звернення | Обов’язкове |
| **Опис** | Детальний опис питання або проблеми | Обов’язкове |
| **Контактна особа** | Ім’я особи для зв’язку | Обов’язкове |
| **Email** | Адреса для отримання відповіді | Обов’язкове |
| **Телефон** | Додатковий номер для зв’язку | Необов’язкове |

Після натискання **Створити звернення** система присвоїть зверненню унікальний номер і статус **Нова**.

## 4. Перегляд статусів та історії власних звернень

У розділі **Мої звернення** клієнт бачить лише власні звернення. Для кожного звернення доступні номер, тема, послуга, дата створення та поточний статус.

Можливі статуси:

| Статус | Значення |
|---|---|
| **Нова** | Звернення створено та очікує опрацювання |
| **В роботі** | Менеджер опрацьовує звернення |
| **Завершена** | Опрацювання звернення завершено |
| **Відхилена** | Звернення відхилено із зазначенням причини |

На сторінці звернення відображається публічна історія: зміни статусу, повідомлення менеджера та коментарі клієнта. Внутрішні коментарі менеджерів клієнту не показуються.

## 5. Скасування звернення

Скасувати звернення можна лише тоді, коли його статус — **Нова**.

Щоб скасувати звернення:

1. Відкрийте потрібне звернення.
2. Натисніть **Скасувати звернення**.
3. Підтвердьте дію.

Після скасування звернення отримує статус **Відхилена**, а в історії з’являється запис про скасування користувачем. Звернення зі статусом **В роботі**, **Завершена** або **Відхилена** клієнт скасувати не може.

## 6. Додавання коментарів

Клієнт може додати коментар на сторінці власного звернення:

1. Відкрийте звернення.
2. Введіть повідомлення у формі **Додати коментар**.
3. Натисніть **Надіслати**.

Коментар клієнта є **публічним** і доступний клієнту та менеджерам, які працюють із зверненням.
